# 2026-10-18 局部照明边界过于明显

## 证据与范围

- 用户提供原版视频 `2026-10-18_21-20-38.mkv` 和 riiablo 截图 `p6.png`。视频抽帧显示原版人物周围亮度逐渐变化，截图中的椭圆形照明边界更明显；不同画面不能作为逐像素或绝对亮度标定。
- D2MOO `source/D2Gfx/src/CmnSubtile.cpp` 的 `sub_6FA71340` 使用 Gouraud 缓存及逐行亮度步进；`D2GFX_FloorTileDraw_6FA73410` 的反编译记录保留了地板相邻光照样本和平均值处理。原版有空间亮度插值，但这些证据不足以确定与当前 shader 完全等价的光源衰减公式。
- 当前 shader 用 `max(ambient, localLight)` 截断衰减尾部，并将连续光强直接量化到 32 档 PL2 色表；两者均可能加重可见边界。

## 修改

- 局部光强在环境亮度和满亮度之间衰减，避免尾部提前碰到环境下限形成明显分界；多个光源继续取最大值。
- 相邻 PL2 行各自查表并解析为 RGB 后插值，保留调色板定义的颜色变化，同时减轻色阶环；不对调色板索引本身做线性过滤。
- 保留当前光照半径、中心平台、环境光提亮和 gamma 配置。这是当前 LibGDX 渲染路径的平滑改进，不宣称已经精确复刻原版照明。

## 验证与待验收

- 已抽取并检查原版视频帧，检查 shader 改动及 `git diff --check`。
- 按用户对极小修改的要求，不运行 Gradle 编译；未执行 GPU shader 编译或实机画面验收。
- 另一台电脑拉取后，在相同时间/区域/亮度设置下检查人物行走时照明外围、室内暗处、火炬及技能光源；确认无色阶环、异常颜色或 shader 加载错误。
