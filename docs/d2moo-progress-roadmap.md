## 说明

这里的百分比按“可运行行为 + 原生分支 + 数据表/RNG + 状态副作用 + 测试覆盖”估算，
不按文件数量或类数量计算。D2MOO 自身也包含 Stub，因此目标是对齐可观察的游戏行为，
不是复制 DLL 的内部实现。
