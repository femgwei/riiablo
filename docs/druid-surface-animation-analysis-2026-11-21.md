# 德鲁伊地裂、火山：客户端生命周期与原生动画时钟

本轮只复用原版 run `20261121-095015-f801398c` 的冻结后台记录，**没有重新启动原版**。在两个技能均一点、其他硬点为零、裸装的配置下，运行真实 Riiablo 技能、移动、客户端展示、加载和动画系统。目标是定位和修复客户端缺失步骤；不进行 GPU 像素验收。

最新职业覆盖为德鲁伊 **4/30 已采集、4/30 已做限定生产对照**，不等于四个技能所有场景均已一致。地裂、火山的比较状态明确保留 `compared_with_remaining_differences`。

## 地裂：发射太密、寿命过短、缺少第二遍动画

原版中心寿命为 80 tick；以第一次创建为零点，在 0、6、12……78 tick 共创建 **14 对**裂缝与烟雾。两层共用出生位置，寿命各 **84 tick**，DCC 各 **41 帧**。实际动画按 `age % 41` 选帧：年龄 40 为帧 40，41 回到 0，82 再回到 0；不能在第一次播放结束后直接删除。

修复前生产展示每 0.09 秒生成一对，合计 **36 对**，每层约 23 tick 即消失。对比到的早期年龄也存在浮点选帧落后；后半段完全没有对应生产年龄。

- 裂缝：原版实际 DCC 样本 1144 个，旧回放仅覆盖 300 个，其中 152 个选帧不同，另有 844 个年龄样本缺失。
- 烟雾：原版样本 1147 个，旧回放仅覆盖 303 个，其中 152 个不同，另有 844 个缺失。

修复后由技能 `calc2` 求发射间隔，本级为 6 tick；在客户端更新前判断发射时钟。两层使用各自表内的 84 tick 寿命和整数原生年龄求帧，不再使用参考包的 0.9 秒短动画。视觉出生点落在整数网格，两层仍共用位置；控制器已过期时不补发特效。

生产回放现在生成 14 对，出生相对时刻与本批一致，**2291/2291 个原版 DCC 样本全部覆盖且帧号一致**。随机落点、裂缝方向序列仍未对齐原版；当前散布仍保留参考实现，整数网格一致不能当作布局已一致。服务端空地图回放仍有 16 个伤害裂缝，未修改其结算逻辑，也未做受控伤害或碰撞验证。

## 火山：本体提前消失、循环边界不对、缺少收尾

原版山体 `volcano` 和火口 `volcano overlay fire` 同时出现，各 **150 tick（6 秒）**。两者各 30 帧，原版 SubStop 为排他边界：

- 山体起手后在 `[17,18)` 循环，即停留第 17 帧；年龄 138 起依次播放 18..29 帧收尾。
- 火口在 `[6,14)` 循环，即 6..13 帧；年龄 134 起播放 14..29 帧收尾。

修复前两层只有约 138 tick（5.5 秒），使用包含终点的参考包循环，且没有原版的完整收尾。山体 142 个原版 DCC 样本中旧回放覆盖 130 个，67 个帧号不同；火口同样覆盖 130/142，119 个不同；各有 12 个末段年龄样本缺失。

修复后两层总寿命跟随控制器，`NativeDruidSurfacePresentation` 按原生年龄、排他循环区间和剩余帧数进入收尾。晚到的快照从已知年龄恢复，不会重新播放完整六秒；到期后即便旧控制器尚未移除也不会继续创建飞石。

生产回放中两层都保留至原生结束阶段，**284/284 个原版本体/火口 DCC 样本全部覆盖且帧号一致**。

## 火山仍未完成的部分

当时原版快照有62个客户端飞石、54个爆炸、52个地面岩浆，生产为29个固定时间参考飞石。后续命中返回采集证实：快照数量不同不能推断随机省略子层；有效CltHit55会分别尝试创建两层，部分飞石提前移除，部分成功创建的子单位未被周期快照采到。

本轮没有将这些数据硬编码成“固定 62 次”，没有改写伤害系统。仍需重建飞石的实际创建来源、原生轨迹/高度、飞行时长和命中/落地分支，并区分地图阻挡、采样条件与客户端独立逻辑。新增比较 JSON 将这些列为剩余差异，不把本体选帧通过扩大为完整火山已重建。
