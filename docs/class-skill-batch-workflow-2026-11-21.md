## 流程与续跑

1. 一次提取职业静态依赖和资源，记录有效表与资源。生成职业/技能族 manifest；不用反复为每个技能重新启动 MPQ 扫描。
2. 在同一角色、装备、目标和状态条件相容时共享一次原版启动。每个技能独立输出、标记输入、确认选中技能和实际回调，再等待本技能效果清理。
3. 召唤、光环、变身、尸体、蓄力、持续施法按场景分批。一个角色学满全部技能会改变协同与被动属性，不适合作为全部技能的零协同 oracle；需要零协同的数值核对仍用隔离存档。
4. 对每个技能分别回放 Riiablo，逐项比对角色模式/序列、创建步骤、资源/层次、方向/位置、帧时钟以及结束/中断。差异定位到生产系统后修复并回归。
5. 状态分开记录：静态收集、运行采集、生产回放、发现差异、修复、限定验证。采集成功不能自动标为动画一致。
