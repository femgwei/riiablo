## Behavior

Every decision ORs UNITFLAG_NOTC into NativeUnitFlags, preserving existing flags.
Before activation, absent targets or distance >=5 wait fifteen frames. The first
decision with a target at distance <5 commits activation and the current frame
before requesting S2. Thereafter a noncombat decision or frame <= deadline uses
S1. An eligible melee decision uses integer self/target coordinates:

- selfX >= targetX and selfY <= targetY: A1, deadline=current+35.
- otherwise selfX > targetX and selfY > targetY: S1, deadline=current+5.
- otherwise selfY < targetY: S1, deadline=current+5.
- otherwise: A2, deadline=current+35.

The first A1 condition has priority at equality. S1 from an ineligible decision
does not extend the deadline. Once activated, far or missing targets request S1
without rearming S2. Owner warp does not reset activation/deadline. A1/A2 use the
ordinary attack lifecycle; S1/S2 are mode changes without injected SkillDo.
All four sequence return modes are S1, following the native end callbacks.
The shared mode-only helper now skips target-facing lookup when the native
target is null. Other mode-only callers retain target-facing behavior.

## Natural results

Real 1.10f MPQ; seed1; 500 ticks; two rows x three difficulties x near/far, plus
an independent repeat: 24 final executions. The three extracted JSONL pairs are
byte identical, with SHA256 in `verification.log`. All final selected scenes
have no fallback, warnings, errors or movement. Twelve near executions each
record 26 ordinary attack SkillDo events and 24 actual damage events; per-row

The twelve far scenes have no actions or damage and remain inactive.

Natural events were generated by the ordinary AI/animation pipeline, without
SkillDo injection or probability/table changes. The near log contains paired
SkillDo events three ticks apart in successive attack cycles (e.g. Normal
ticks37/40 then75/78). These are event observations, not a claim that 26 distinct
attacks occurred or that native per-animation action points are fully aligned.
No arena oracle was added: all selected scenes remain BASELINE_ONLY, and action
counts are not treated as full behavioral acceptance. Each archived journal has
1180 entries; 1176 NOT_RUN entries per run are excluded from execution/pass
counts. Raw scene logs and full journals are preserved in scenes.zip files.

## Remaining limits

Overall remains PARTIAL. The AI uses a local elapsed-frame clock; native global
event scheduling, freeze/event ordering and exact end-animation callback timing
are not ported by this batch. Returning sequences to S1 represents the native
mode transition, not a complete engine-level callback port. Per-animation
action-point parity, natural alternative-quadrant scenarios, reward/XP handling,
real terrain, GL/TCP presentation and whole-directory regression remain
unaccepted. NOTC is passed to the existing reward system; this batch does not
change or validate its complete reward semantics. Final verification is against
the fixed committed-source snapshot plus this batch, not the concurrently
changing uncommitted working tree. Source hashes in verification.log prove both
production files and the test match the working copies intended for commit.

directory. D2_HOME must point to the real 1.10f installation. The arena script
sets the installation path used in this run; adjust for another machine.
