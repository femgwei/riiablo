### 2026-09-11 复杂区域技能多人快照语义

- Riiablo 网络层为权威 Missile 追加技能 ID/技能等级，为 Unit State 追加来源实体、
  来源技能和周期时钟；客户端只恢复表现，不执行服务器状态/导弹逻辑。
- Firestorm、Fissure、Volcano、Armageddon、Hurricane 已锁定为单一权威导弹来源；
  `SrvDo124` Hurricane 即使原始表现名只位于 `cltMissileA`，网络客户端也不重复创建。
- Hydra 按 D2MOO `SrvDo144` 保持三个 Monster Unit，不错误建模为 Missile。
- 1.10f hurricane/armageddon States 行不声明 Overlay，效果由权威导弹实体承担。
- 17 个区域技能专项用例、33 个状态序列化相邻回归和 D2GS 编译通过；隐藏营地因离屏
  测试目录缺少 MPQ 未能启动。
- 下一项：D2GS 无窗口双客户端验证 MonsterP/MissileP/StateP 的一致实体集合和删除时序。

## 项目概述
本工程目的是将 D2MOO (C++) 代码库移植到 D2MOO_JAVA (Java) 代码库，实现 1:1 的代码逻辑移植。

## 移植规范

### 代码规范
1. **日志函数封装**：需要封装统一的日志函数
2. **调试日志语言**：调试日志采用英文
3. **代码注释语言**：代码注释采用中文
4. **目录结构**：在 d2mod_java 目录下按 d2mod 目录结构生成对应的目录和类
5. **移植方式**：按类逐函数移植，严格保证代码逻辑一致性

### 问题记录
如果遇到以下情况，需要在本文档中标注：
- 函数逻辑不明确，无法确定移植方式
- 依赖的外部库或函数在 Java 中无法直接对应
- C++ 特性在 Java 中无法直接实现的部分
- 需要特殊处理的内存管理相关代码
